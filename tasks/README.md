# 📋 Mission Tasks & Artifacts Directory (`tasks/`)

This directory stores historical task archives, mission outputs, and generated deliverables produced by the collaborative multi-agent pipeline.

---

## 🗂️ Task Directory Structure

When a task is dispatched through Mission Control or `main.py`, a dedicated folder is created under `tasks/` using the following timestamped convention:

```text
tasks/
├── task_YYYYMMDD_HHMMSS/
│   ├── metadata.json       # Task goal, participating agents, execution timestamps
│   ├── step_gemini_plan.txt# Decomposed subtask plan generated by Gemini Leader
│   ├── worker_outputs.json # Raw outputs from each specialist agent (DeepSeek, ChatGPT, etc.)
│   ├── debate_log.txt      # Multi-agent critique and discussion transcript
│   └── final_deliverable.md# Polished, approved outcome verified by Gemini Leader
└── README.md
```

---

## 🔍 Task Lifecycle Stages

1. **Planning (`Define & Plan`)**: Gemini Leader ingests the user's objective and generates atomic instructions for each selected specialist.
2. **Execution (`Build`)**: Specialist agents execute in parallel or sequentially within their isolated Chrome tiles.
3. **Debate & Critique (`Verify`)**: Workers critique and refine each other's deliverables to resolve discrepancies.
4. **Approval & Packaging (`Ship`)**: Gemini Leader conducts final quality audits and writes the output to the task archive.
