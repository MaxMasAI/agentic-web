System Requirements
===================

Minimum System Requirements:
* **Operating System**: Windows 10/11 (64-bit), macOS 13.0+ (Apple Silicon or Intel), or Linux (Ubuntu 20.04+, Debian 11+, Arch, Fedora).
* **Python**: Python 3.10, 3.11, 3.12, or 3.13.
* **RAM**: 8 GB RAM minimum (16 GB recommended for local vector indexing & Ollama models).
* **Disk Space**: 2 GB free disk space.
