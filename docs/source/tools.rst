Built-in Tools Suite
====================

The Agentic Web platform provides an extensive suite of built-in interactive tools and plugins to supercharge productivity and AI workflows.

Available Tools
---------------

Notepad
~~~~~~~
A lightweight, markdown-enabled scratchpad for quick notes, code snippets, and structured brainstorming.

Painter
~~~~~~~
A full-featured canvas editor for sketching diagrams, wireframes, visual annotations, and image generation concepts.

Media Player & Video Audio Suite
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Integrated media player supporting MP3, WAV, MP4, WebM formats, voice synthesis previews, and transcription inspection.

Code Interpreter & Terminal
~~~~~~~~~~~~~~~~~~~~~~~~~~~
Secure sandboxed terminal runner for Python, JavaScript, and shell command execution with real-time output streaming.

Web Search & Scraper
~~~~~~~~~~~~~~~~~~~~
Built-in web search and HTML/Markdown scraper tools enabling LLMs to browse the live internet and fetch relevant documentation.
