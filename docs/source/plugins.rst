Service Plugins Ecosystem
=========================

Built-in integrations powering agent actions across external tools and APIs:

* **GitHub & Bitbucket**: Repositories, files, issues, pull requests, and commits.
* **Google Suite**: Gmail, Calendar, Drive, Docs, Keep, YouTube, Contacts, Maps.
* **Telegram**: Bot API and user-mode messaging and media transfers.
* **Remote Servers**: SSH terminal commands, SFTP/FTP/SMB file transfers with sanitized credentials.
* **System OS**: Safe command execution with `auto_cwd`.
* **Web Search & Wikipedia**: Google CSE, Bing, DuckDuckGo, and multilingual Wikipedia.
