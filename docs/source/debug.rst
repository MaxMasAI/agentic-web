Debug & Diagnostics
===================

Inspect real-time agent execution, pipeline traces, and raw LLM payload structures.

Debugging Options
-----------------
* **Log Agents Usage to Console**: Prints full agent workflow routing, slot inputs, and activations to standard output.
* **Verbose LLM Payload Logging**: Outputs raw prompt tokens, tool call JSON schemas, and response metadata.
* **Process Tracking**: Tracked PIDs and subprocess monitors ensure zero zombie processes upon exit.
