Introduction
============

Agentic Web Workstation is a desktop AI control center and autonomous multi-agent orchestration platform.

Core Capabilities
-----------------
* **Visual Agents Builder**: Zero-code node graph editor for multi-agent workflows.
* **Autonomous Computer Use**: Browser and desktop interaction using mouse, keyboard, and screen capture.
* **Persistent Memory**: SQLite-backed continuous memory with ChatGPT-style conversation management.
* **Plugin Ecosystem**: GitHub, Bitbucket, Telegram, Google Suite, Remote Servers (SSH/FTP), and Web Search.
