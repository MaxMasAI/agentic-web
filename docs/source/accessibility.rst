Accessibility
=============

The Agentic Web Workstation provides comprehensive accessibility features for enhanced usability:

Features
--------
* **Speech Synthesis (TTS)**: Reads assistant responses out loud using native platform speech engines.
* **Microphone Voice Input (STT)**: Dictate prompts directly into any input field.
* **Cyberpunk High-Contrast Mode**: Enhanced visual borders, bright neon accents, and crisp font rendering.
* **Full Keyboard Navigation**: Complete Tab-indexing and keyboard shortcuts (`Ctrl+B`, `Ctrl+N`, `Ctrl+K`).
* **Font Scaling**: Adjust font sizes dynamically across plain text, notepads, input fields, and toolboxes.
