Assistant Modes
===============

Switch between specialized working modes via the sidebar:

Modes
-----
* **Universal Chat**: Interactive conversational interface with streaming responses and SQLite history.
* **Chat with Files (RAG)**: Conversational questioning over uploaded PDFs, docs, and codebases.
* **Deep Research**: Autonomous multi-step web crawling, fact aggregation, and comprehensive report generation.
* **Media Studio**: Image synthesis (DALL-E 3, Imagen 3, SDXL) and video production studio.
