User Profiles & Authentication
==============================

Manage account sessions, OAuth 2.0 PKCE tokens, and security vaults.

Zero-Setup Web Browser Sign-In
------------------------------
Authenticate with Google, OpenRouter, Hugging Face, or GitHub via standard OAuth 2.0 loopback callbacks (`http://127.0.0.1:8085/callback`).

Session Persistence
-------------------
Sessions are encrypted and saved locally in `json/user_auth.json`.
