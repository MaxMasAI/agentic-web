Supported Models & Inference
============================

Agentic Web connects to top frontier and open-source models:

Supported Providers
-------------------
* **Google Gemini**: Gemini 2.0 Flash, Gemini 1.5 Pro (Multimodal & Long-Context).
* **OpenRouter**: Access to 100+ models (Claude 3.5 Sonnet, GPT-4o, DeepSeek-R1, Llama 3.3).
* **Anthropic**: Claude 3.5 Sonnet, Claude 3 Opus, Claude 3.5 Haiku.
* **OpenAI**: GPT-4o, GPT-4o-mini, o1, o3-mini.
* **DeepSeek**: DeepSeek-V3, DeepSeek-R1.
* **Local Ollama**: Offline inference for Llama 3, Qwen 2.5, Mistral, DeepSeek-Coder.
