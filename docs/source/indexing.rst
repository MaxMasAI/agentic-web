Vector Indexing & RAG
=====================

Document search and vector store integrations for contextual agent recall.

Supported Vector Stores
-----------------------
* **Local SQLite Vector**: Zero-dependency local embedding database.
* **ChromaDB**: Lightweight vector store for embedded semantic search.
* **FAISS**: High-throughput similarity search.
* **Qdrant / Pinecone**: Production-grade cloud vector databases.
* **OpenAI Vector Stores**: Native cloud file indexing.
