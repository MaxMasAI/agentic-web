Agent Presets & Workflow Patterns
==================================

Standard multi-agent orchestration presets supported by the platform:

1. **Simple Agent**: Single model loop with function execution.
2. **Feedback Loop**: Critic-evaluator refinement cycle.
3. **Experts (Co-op)**: Multi-specialist consensus swarms.
4. **Experts + Feedback**: Multi-agent co-op with evaluator verification.
5. **Planner + Workers**: Hierarchical task breakdown and worker execution.
6. **Autonomous Researcher**: Deep web browsing and synthesis loop.
7. **Evolve Workflow**: Evolutionary genetic prompt optimization.
8. **B2B Pipeline**: Structured business pipeline with approval gates.
9. **Supervisor + Subagent Workers**: Leader-worker delegation squads.
10. **Auto-GPT Loop**: Fully autonomous task completion loop.
