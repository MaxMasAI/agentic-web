System Architecture

5-Tier Enterprise Operating Architecture

Agentic Web is built on a non-blocking, decoupled 5-tier architecture ensuring fluid UI responsiveness (60 FPS), robust multi-agent background execution, military-grade security sandboxing, and resilient failover.

Tier 1: Non-Blocking UI

PySide6 Desktop & Monaco Studio Layer

Native Qt6 GUI with zero UI-thread blocking. Thread-safe Qt Signals (`token_emitted`, `status_changed`, `task_finished`) push live telemetry directly into Mission Control, Task Dispatch, Canvas IDE, and Token Manager.

Tier 2: Async Workers

Multi-Threaded QThread & QThreadPool Cluster

Dedicated worker threads managing LLM token streaming, voice processing (ASGI FastAPI + WebSocket bridge on port 8000), and Playwright Chrome DevTools Protocol (CDP on port 9222).

Tier 3: Security Barrier

Security Guard & Dual-Mode Sandboxing

Deep regex command inspection intercepting hazardous OS operations (`rm -rf /`, `del /f`, fork bombs, reverse shells) with Docker container isolation and local restricted subprocess sandboxes.

Tier 4: Resilient Gateway

Token Bucket Rate Limiting & Circuit Breaker

Granular RPM/TPM token-bucket governors, exponential backoff with full jitter for HTTP 429/5xx, and a 3-state Circuit Breaker (`CLOSED`, `OPEN`, `HALF_OPEN`) with automated model failover.

Tier 5: Persistence

ACID SQLite WAL Database (`db.sqlite`)

High-concurrency SQLite Write-Ahead Logging (WAL) state store managing the PID process registry, task history, neural memory embeddings, and token ledgers with atomic guarantees.

👑 Dynamic Master Leader Switching Logic

If any custom agent is registered with "is_leader": true, the platform dynamically promotes that model to LEAD_AGENT. Google Gemini is automatically placed into SPECIALIST_AGENTS (acting as a multimodal evaluator). When the custom leader is deleted or reset, Gemini automatically returns as default Master Orchestrator without data corruption.
