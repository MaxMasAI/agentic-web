# ⬇️ Downloads & Generated Assets Directory (`downloads/`)

This directory houses all visual assets, generated images, code files, and downloadable deliverables produced by agents during automated runs.

---

## 🎨 Asset Categories

1. **AI Images & Mockups**:
   - High-resolution visuals generated via **OpenAI DALL-E 3** or **Meta AI** during campaign tasks.
2. **Code Deliverables**:
   - HTML, CSS, JavaScript, and Python script bundles generated by **DeepSeek** and **ChatGPT**.
3. **Documents & Reports**:
   - Exported markdown reports, executive briefs, and CSV data tables.

---

## 🔄 Auto-Extraction Pipeline (`downloader.py`)

- During agent execution, `downloader.py` automatically monitors Chrome DOM mutations for generated `<img>`, `<canvas>`, and download triggers.
- Downloaded assets are linked in the **Folder Explorer** and **Mission Archive** for 1-click preview and download.
