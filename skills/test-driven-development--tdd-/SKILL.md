# Test-Driven Development (TDD) Protocol

## 🎯 Objective
Follow the Red-Green-Refactor discipline: write failing unit tests first, prove failure, implement minimal code to pass, and refactor for senior-grade readability.

## 🚨 Critical Rules
1. Write isolated assertions with verifiable boundary conditions.
2. Eliminate mock leaks and test state pollution.
